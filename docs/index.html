  권역 자기복잡도 σ(반경 25 km, 추세제거 표준편차)
  n_h ∝ A_h·σ_h → 밀도 ρ ∝ σ → 권장 간격 L = 1/√ρ
  현 등가 간격 = 1등 지자기점 관측망 30점(명목 30,
  survey_review.html 과 같은 명단)의 √담당면적 — 국토
  격자 위 이산 보로노이. 최근접거리 × 2 는 측점 위에서 0 이
  되어 권장 간격과 나눌 수 없으므로 폐기(2026-08-27).
  목표 80점 = 현 관측망 30 + Track C 신규 50 —
  분모와 분자를 같은 모집단으로 맞춘 것. LMM 투입 16점은
  「그중 현재 모델에 들어간 자료」이지 관측망이 아니다.
