- **수집기**: `kasa_geomag.py` (인증키·로그인 불필요)
- **수집일**: 2026-08-04
- **용도**: LMM 외부장(일변화) 보정용 상시관측 기준자료. IGRF epoch(2015–2020 / 2020–2025)
  경계에 맞춰 **2019 자료**와 **2020년 이후 자료**를 분리 적용.

## 2. 실제 수집한 파일 (`data/kasa/`)

**제주·강릉·이천 — 2019~2025 관측소별·연도별** (`kasa_{GN|JJ|ICH}_YYYY.csv`, 각 ~40 MB / 약 52.6만 행):

> 파일은 **UTF-8 BOM**(한글 Excel에서 안 깨짐), **관측소별로 분리**(3관측소 합치면
> 연 약 158만 행으로 Excel 한도 1,048,576 초과 → 관측소별이면 연 최대 ~52.7만 행).
> GN=강릉, JJ=제주, ICH=이천, BOH=보현산.

| 연도 | 강릉 | 제주 | 이천 | 비고 |
|---|---|---|---|---|
| 2019 | 99.3 % | 98.0 % | **100.0 %** | 전 관측소 최상 |
| 2020 | 97.3 % | 98.5 % | 91.1 % | |
| 2021 | 97.7 % | 99.1 % | **60.0 %** | 이천 급감 시작 |
| 2022 | 97.9 % | 97.0 % | 97.6 % | 결측 1구간(01-21~01-25 전 관측소) |
| 2023 | 95.5 % | **71.9 %** | 77.9 % | 제주·이천 저조 |
| 2024 | 90.5 % | 98.7 % | **62.1 %** | 이천 저조 |
| 2025 | 98.4 % | 99.6 % | **52.3 %** | 이천 최저 |

(유효율 = 비결측 분(minute) / 연간 분. 분모는 윤년 반영)

**보현산**: `kasa_BOH_2020-07.csv` (실측 확인 구간, 21,251분). 그 외 구간은
무효/부재이므로 미수집.

포맷: 3관측소 = `station,time_kst,X_nT,Y_nT,Z_nT,F_nT` / 보현산 = `station,time_kst,H,D,Z`.
결측치는 `-99999`. 시각은 **KST**(CYG·Kp는 UT → 결합 시 −9h 변환 필요).

**활용 시 유의**
- **강릉·제주는 전 기간 양호**(대체로 95%+). 외부장(일변화) 보정의 주 기준으로 적합.
- **이천은 2021년부터 열화**(60→52%), 2023·2025 특히 낮음 → 수도권 보정에 단독 의존 금지.
  자문회의의 "이천 관측기 점검(2023.10~)" 정황과 일치하나, 실데이터는 부분적으로 존재.
- **제주 2023년(72%)** 은 일시 저조 — 그 해 제주 기준자료는 결측 확인 후 사용.

## 3. ⚠️ 성분 규약 주의 (반드시 확인)

관측소마다 X/Y 성분의 기준 좌표계가 다르다:

| 관측소 | 예(2019-05-08 23:59) | 판정 |
|---|---|---|
| 이천 | X=29744, **Y=−4153** → D=atan(Y/X)=−7.95° | 지리 정북 기준(절대 편각 근사 가능) |
| 강릉 | X=29609, **Y=−293** → D=−0.57° | 센서/변화계 기준(절대 편각 아님) |
| 제주 | X=33167, Y=−485 | 센서/변화계 기준 |

- **일변화(외부장) 보정에는 문제없음** — 정온 기준선 대비 **편차(ΔX,ΔY,ΔZ)** 만 쓰므로
  각 관측소 내부 일관성만 있으면 된다.
- 그러나 **절대 편각 D 로 직접 환산 금지**(강릉·제주). F는 세 관측소 모두 벡터크기와 정합.
- 보현산 H/D/Z 컬럼 규약도 별도이며 2019는 무효이므로 사용 전 재검증.

## 4. LMM epoch 분리 관점 정리

| 필드자료 | IGRF epoch | 대응 관측소 기준자료 | 상태 |
|---|---|---|---|
| 2019 야장(미원·이원·성산·장흥) | 2015–2020 (IGRF-13) | 제주·강릉·이천 2019 | **확보** ✅ |
| 2020+ 성과/야장 | 2020–2025 (IGRF-14) | 제주·강릉·이천 2020~2025 | **확보 가능**(야장 일자 확정 후 창별 수집) |
| — 보현산 보조 | — | 2020 일부만 | 참고용 |

- 거제·남지 2019 야장 시기는 위 3구간에 포함되지 않았을 수 있음 → 야장 일자 확인 후
  해당 창을 추가 수집.
- 2020+는 **성과/야장의 실제 관측일**을 알아야 표적 수집이 가능(자문회의 후속: 2020~25
  야장 확보 필요와 직결).

## 5. 추가 수집 방법

```bash
python kasa_geomag.py --probe                                  # 커버리지 재조사
python kasa_geomag.py --station three --start 2022-05-01 --end 2022-05-31
python kasa_geomag.py --station boh   --start 2020-07-01 --end 2020-07-31
```

- 요청당 상한: 3관측소 5일, 보현산 1개월(스크립트가 자동 분할).
- 정부 서버 부하 고려 요청 간 0.8초 지연. 다년 연속 대량 수집은 지양하고 **야장 일자 창**만 표적 수집 권장.
